# karenpsol.com.br

Site da deputada estadual eleita Karen Santos (PSOL-RS).

- `index.html` – página única (Trajetória, Projetos, Passe Livre, Discursos, Taquigrafias, Redes, Contato)
- `arquivo-tribuna.json` – falas da Karen na tribuna da Câmara de Porto Alegre (2019–2026), com links para os Anais
- `img/` – imagens

Hospedado na Vercel; domínio no Registro.br.
